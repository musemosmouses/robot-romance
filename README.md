## The entry

> Are you a CAPTCHA? Because I keep proving I'm human just to get closer to you.

78 characters, one line. The joke turns the machine's own gate against it: the speaker keeps proving they are human — the one thing a CAPTCHA asks for — just to get nearer to the machine doing the asking.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
